# Examples

Copy one of these into your own repository. Each has its own `README.md`
listing its commands with expected output.

- [consumer-ci](consumer-ci/) GitHub Actions caller for the consumer workflow.
- [docs-ci](docs-ci/) GitHub Actions caller for the docs workflow.
- [gitlab-ci](gitlab-ci/) GitLab CI starter pipeline, without the GitHub workflow features listed in its README.
- [adopt-polyglot](adopt-polyglot/) a Python, Rust, JS/TS and C++ tree adopted with `dx generate`.
- [shared-rust](https://github.com/devhusdk/rules_dx/tree/main/examples/shared-rust) one Rust task board built for CLI, browser, WASI, Android and Apple.
