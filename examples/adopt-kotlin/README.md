# Adopt Kotlin example

Kotlin Maven-layout tree with a `greet` package and a stdlib-only `solo` package.

```sh
bazel run @rules_dx//:dx -- init //examples/adopt-kotlin/...
bazel run @rules_dx//:dx -- generate //examples/adopt-kotlin/...
bazel build //examples/adopt-kotlin/...
bazel test //examples/adopt-kotlin/...
```

Both tests pass (`greet_test`, `pure_test`).
