# Adopt PowerShell example

PowerShell tree with a `greet` package and a stdlib-only `solo` package.

```sh
bazel run @rules_dx//:dx -- init //examples/adopt-powershell/...
bazel run @rules_dx//:dx -- generate //examples/adopt-powershell/...
bazel build //examples/adopt-powershell/...
bazel test //examples/adopt-powershell/...
```

Both tests pass (`greet_test`, `pure_test`).
